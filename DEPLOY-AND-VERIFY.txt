Firebase Google sign-in (not automatically fixed by GitHub upload)
-----------------------------------------------------------------
- Authentication > Sign-in method: Google enabled, support email configured.
- Authentication > Settings > Authorized domains: add exact hostname:
      kiratveersinghralhan-hue.github.io
  without https:// or /BuisnessManagment/.
- Keep Email/Password enabled and Anonymous disabled.
- Google provider requires an actual Google account with a verified
  @chitkara.edu.in email. Email accounts hosted only by Microsoft
  are NOT automatically Google accounts.
- If auth/internal-error remains, do not modify Realtime Database rules.
  On desktop Chrome F12 > Console and Network > filter by 'identitytoolkit',
  retry login and inspect error code. Do not share tokens or passwords.
- Firebase official help: https://firebase.google.com/docs/auth/faq-and-troubleshooting
- For a misconfigured Google OAuth client, validate client ID / secret
  through Firebase Console and Google Cloud, or follow Firebase's
  documented disable/re-enable Google provider procedure carefully.
- Account linking must be implemented/tested separately before students
  use a second provider for an existing email, to avoid duplicate UIDs.
